# API 参考

## 基础信息

- **Base URL**: `https://your-comments-server.com`
- **认证方式**: JWT Bearer Token（放在 `Authorization` header 中）
- **响应格式**: JSON

### 通用响应格式

```json
{
  "err": "ok",
  "msg": "可选的消息",
  "data": {}
}
```

## 认证接口

### POST `/api/auth/register`

注册新用户。

**请求体：**

```json
{
  "email": "user@example.com",
  "password": "password123",
  "nickname": "用户昵称"
}
```

**响应：**

```json
{
  "err": "ok",
  "data": {
    "id": 1,
    "email": "user@example.com",
    "nickname": "用户昵称"
  }
}
```

### POST `/api/auth/login`

用户登录，返回 JWT。

**请求体：**

```json
{
  "email": "user@example.com",
  "password": "password123"
}
```

**响应：**

```json
{
  "err": "ok",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIs...",
    "user": {
      "id": 1,
      "email": "user@example.com",
      "nickname": "用户昵称",
      "role": "user"
    }
  }
}
```

### GET `/api/auth/me`

获取当前登录用户信息。

**Header**: `Authorization: Bearer <token>`

**响应：**

```json
{
  "err": "ok",
  "data": {
    "id": 1,
    "email": "user@example.com",
    "nickname": "用户昵称",
    "role": "user",
    "avatar": null
  }
}
```

### POST `/api/auth/logout`

退出登录，清除 cookie。

### PUT `/api/auth/password`

修改密码。

**请求体：**

```json
{
  "currentPassword": "old_password",
  "newPassword": "new_password"
}
```

## 平台接口（公开）

### GET `/api/platform/comments`

分页获取评论列表（无需认证）。

**Query 参数：**

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| appId | string | 是 | 应用 ID |
| chapterId | number | 否 | 章节 ID |
| bookId | number | 否 | 书籍 ID |
| segmentId | number | 否 | 段落 ID |
| page | number | 否 | 页码，默认 1 |
| limit | number | 否 | 每页数量，默认 20，最大 100 |

**响应：**

```json
{
  "err": "ok",
  "data": {
    "list": [
      {
        "id": 1,
        "bookId": 100,
        "chapterId": 10,
        "chapterName": "第一章",
        "segmentId": 5,
        "content": "评论内容",
        "userId": 1,
        "nickname": "用户昵称",
        "avatar": null,
        "level": 1,
        "likeCount": 0,
        "dislikeCount": 0,
        "createdAt": "2024-01-01T00:00:00.000Z"
      }
    ],
    "pagination": {
      "page": 1,
      "limit": 20,
      "total": 100,
      "totalPages": 5
    }
  }
}
```

### POST `/api/platform/comments`

发表评论（需认证）。

**Header**: `Authorization: Bearer <token>`

**请求体：**

```json
{
  "appId": "app_xxx",
  "bookId": 100,
  "chapterId": 10,
  "chapterName": "第一章",
  "segmentId": 5,
  "content": "评论内容",
  "rootId": null,
  "quoteId": null
}
```

**响应：**

```json
{
  "err": "ok",
  "data": {
    "id": 101,
    "bookId": 100,
    "chapterId": 10,
    "content": "评论内容",
    "userId": 1,
    "nickname": "用户昵称",
    "level": 1,
    "createdAt": "2024-01-01T00:00:00.000Z"
  }
}
```

### POST `/api/platform/proxy-login`

代理登录。

**请求体：**

```json
{
  "appId": "app_xxx",
  "proxyToken": "encoded.signature",
  "externalId": "user_12345",
  "externalEmail": "user@third-party.com",
  "externalNick": "第三方昵称"
}
```

## 管理员接口

所有管理员接口需要 `role=admin` 的 JWT 认证。

### GET `/api/admin/stats`

获取统计数据。

```json
{
  "err": "ok",
  "data": {
    "appCount": 10,
    "commentCount": 5000,
    "todayComments": 128
  }
}
```

### GET `/api/admin/apps`

获取应用列表。

**Query**: `page`, `limit`, `search`

### POST `/api/admin/apps`

创建应用。

```json
{
  "name": "新应用",
  "domains": "example.com,*.example.com"
}
```

### GET `/api/admin/apps/:id`

获取应用详情。

### PUT `/api/admin/apps/:id`

更新应用。

```json
{
  "name": "更新后的名称",
  "domains": "new-domain.com",
  "isActive": true
}
```

### GET `/api/admin/apps/:id/secret`

获取应用 Secret。

### POST `/api/admin/apps/:id/reset-secret`

重置应用 Secret。

### GET `/api/admin/comments`

获取评论列表。

**Query**: `page`, `limit`, `appId`, `chapterId`, `search`

### DELETE `/api/admin/comments/:id`

删除评论。

## 错误码

| HTTP 状态码 | 说明 |
|---|---|
| 400 | 请求参数错误 |
| 401 | 未认证或认证失败 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 409 | 资源冲突（如邮箱已注册） |
| 429 | 频率限制 |
| 500 | 服务器内部错误 |
