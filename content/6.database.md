# 数据库模型

本文档描述评论平台的数据库结构，基于 Prisma ORM 定义，直接兼容你现有的 MySQL 数据库。

## 概览

```
User ───< Comment >─── App >─── ThirdPartyUser
                           └─── Nonce
```

## 原有数据表（无需迁移）

以下表与原有 Python/Tornado 项目完全一致，**无需任何数据迁移**：

### readers（User 模型）

| Prisma 字段 | MySQL 列 | 类型 | 说明 |
|---|---|---|---|
| id | id | INT PK | 自增主键 |
| email | email | VARCHAR(200) | 邮箱，唯一 |
| nickname | nickname | VARCHAR(100) | 昵称 |
| avatar | avatar | VARCHAR(200) | 头像 URL |
| password | password | VARCHAR(255) | bcrypt 哈希密码 |
| role | role | VARCHAR(50) | 角色：`user` 或 `admin` |
| isActive | is_active | TINYINT(1) | 是否启用（对应原 `is_active`） |
| createdAt | create_time | DATETIME | 创建时间 |
| updatedAt | update_time | DATETIME | 更新时间 |
| accessTime | access_time | DATETIME | 最后登录时间 |
| lastRead | last_read | DATETIME | 最后阅读时间 |
| permission | permission | VARCHAR(100) | 权限位（原有字段保留） |

### reviews（Comment 模型）

| Prisma 字段 | MySQL 列 | 类型 | 说明 |
|---|---|---|---|
| id | id | INT PK | 自增主键 |
| appId | app_id | INT | 所属应用（0 表示未分配，原有数据默认为 0） |
| bookId | book_id | INT | 书籍 ID |
| chapterId | chapter_id | INT | 章节 ID |
| segmentId | segment_id | INT | 段落 ID |
| cfi | cfi | VARCHAR(255) | EPUB CFI 定位 |
| cfiBase | cfi_base | VARCHAR(255) | EPUB CFI base |
| type | type | INT | 类型：1=文字, 2=点赞, 3=踩 |
| level | level | INT | 楼层 |
| content | content | VARCHAR(1024) | 评论内容 |
| createdAt | create_time | DATETIME | 创建时间 |
| updatedAt | update_time | DATETIME | 更新时间 |
| geo | geo | VARCHAR(255) | IP 地址 |
| userId | user_id | INT FK | 发布者 → readers.id |
| rootId | root_id | INT | 根评论 ID |
| quoteId | quote_id | INT | 引用评论 ID |
| likeCount | like_count | INT | 点赞数 |
| dislikeCount | dislike_count | INT | 踩数 |

### review_books

| Prisma 字段 | MySQL 列 | 类型 |
|---|---|---|
| id | id | INT PK |
| title | title | VARCHAR(255) |
| alias | alias | VARCHAR(5120) |

### review_chapters

| Prisma 字段 | MySQL 列 | 类型 |
|---|---|---|
| id | id | INT PK |
| bookId | book_id | INT |
| title | title | VARCHAR(255) |
| alias | alias | VARCHAR(5120) |
| parents | parents | VARCHAR(5120) |

## 新增数据表（平台化功能）

### apps

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 自增主键 |
| app_id | VARCHAR(100) | 应用唯一标识 |
| secret | VARCHAR(255) | HMAC 签名密钥 |
| name | VARCHAR(200) | 应用名称 |
| domains | TEXT | 允许域名，逗号分隔 |
| is_active | TINYINT(1) | 是否启用 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### third_party_users

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 自增主键 |
| app_id | INT FK | 关联 apps.id |
| external_id | VARCHAR(200) | 第三方用户 ID |
| external_email | VARCHAR(200) | 第三方邮箱 |
| external_nick | VARCHAR(100) | 第三方昵称 |
| internal_user_id | INT FK | 映射的 readers.id |
| last_login_at | DATETIME | 最后登录时间 |
| created_at | DATETIME | 创建时间 |

唯一约束：`(app_id, external_id)`

### nonces

| 字段 | 类型 | 说明 |
|---|---|---|
| id | INT PK | 自增主键 |
| app_id | INT FK | 关联 apps.id |
| nonce | VARCHAR(255) | 唯一随机字符串 |
| expires_at | DATETIME | 过期时间 |
| created_at | DATETIME | 创建时间 |

## 使用说明

由于你的 MySQL 数据库中已有 `readers`、`reviews`、`review_books`、`review_chapters` 表，只需要：

1. 配置 `.env` 中的 `DATABASE_URL` 连接你的 MySQL
2. 运行 `npm run db:generate` 生成 Prisma 客户端
3. 手动创建新增表（apps、third_party_users、nonces），或直接运行以下 SQL：

```sql
-- 创建应用表
CREATE TABLE IF NOT EXISTS `apps` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `app_id` VARCHAR(100) UNIQUE NOT NULL,
  `secret` VARCHAR(255) NOT NULL,
  `name` VARCHAR(200) NOT NULL,
  `domains` TEXT DEFAULT '',
  `is_active` TINYINT(1) DEFAULT 1,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建第三方用户映射表
CREATE TABLE IF NOT EXISTS `third_party_users` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `app_id` INT NOT NULL,
  `external_id` VARCHAR(200) NOT NULL,
  `external_email` VARCHAR(200),
  `external_nick` VARCHAR(100),
  `internal_user_id` INT NOT NULL,
  `last_login_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY `uk_app_external` (`app_id`, `external_id`),
  FOREIGN KEY (`app_id`) REFERENCES `apps`(`id`),
  FOREIGN KEY (`internal_user_id`) REFERENCES `readers`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 创建 nonce 防重放表
CREATE TABLE IF NOT EXISTS `nonces` (
  `id` INT AUTO_INCREMENT PRIMARY KEY,
  `app_id` INT NOT NULL,
  `nonce` VARCHAR(255) UNIQUE NOT NULL,
  `expires_at` DATETIME NOT NULL,
  `created_at` DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (`app_id`) REFERENCES `apps`(`id`),
  INDEX `idx_nonce` (`nonce`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

4. 运行 `npm run db:seed` 创建管理账号和演示应用
