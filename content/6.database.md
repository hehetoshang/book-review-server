# 数据库模型

本文档描述评论平台的数据库结构，基于 Prisma ORM 定义。

## 概览

```
User ───< Comment >─── App >─── ThirdPartyUser
                           └─── Nonce
```

## User（用户）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Int (PK) | 自增主键 |
| email | String (Unique) | 邮箱，唯一 |
| nickname | String | 昵称 |
| avatar | String? | 头像 URL |
| password | String | bcrypt 哈希密码 |
| role | String | 角色：`user` 或 `admin` |
| isActive | Boolean | 是否启用 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |
| accessTime | DateTime? | 最后登录时间 |

关系：
- `comments`: 该用户发布的所有评论
- `thirdParties`: 第三方账号映射

## App（应用）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Int (PK) | 自增主键 |
| appId | String (Unique) | 应用唯一标识，格式 `app_xxx` |
| secret | String | 签名密钥，用于代理登录 |
| name | String | 应用名称 |
| domains | String | 允许域名，逗号分隔 |
| isActive | Boolean | 是否启用 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

关系：
- `comments`: 该应用下的所有评论
- `nonces`: 已使用的 nonce 记录

## ThirdPartyUser（第三方用户映射）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Int (PK) | 自增主键 |
| appId | Int (FK) | 关联应用 |
| externalId | String | 第三方平台的用户 ID |
| externalEmail | String? | 第三方用户邮箱 |
| externalNick | String? | 第三方用户昵称 |
| internalUserId | Int (FK) | 映射的内部用户 ID |
| lastLoginAt | DateTime | 最后登录时间 |
| createdAt | DateTime | 创建时间 |

唯一约束：`(appId, externalId)`

## Nonce（防重放）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Int (PK) | 自增主键 |
| appId | Int (FK) | 关联应用 |
| nonce | String (Unique) | 唯一随机字符串 |
| expiresAt | DateTime | 过期时间 |
| createdAt | DateTime | 创建时间 |

## Comment（评论）

| 字段 | 类型 | 说明 |
|---|---|---|
| id | Int (PK) | 自增主键 |
| appId | Int (FK) | 所属应用 |
| bookId | Int | 书籍 ID |
| bookTitle | String | 书籍名称 |
| chapterId | Int | 章节 ID |
| chapterName | String | 章节名称 |
| segmentId | Int | 段落 ID |
| cfi | String | EPUB CFI 定位 |
| cfiBase | String | EPUB CFI base |
| content | String | 评论内容 |
| userId | Int (FK) | 发布者 |
| rootId | Int? | 根评论 ID（回复链） |
| quoteId | Int? | 引用评论 ID |
| level | Int | 楼层 |
| type | Int | 类型：1=文字 |
| geo | String | IP 地址 |
| likeCount | Int | 点赞数 |
| dislikeCount | Int | 踩数 |
| createdAt | DateTime | 创建时间 |
| updatedAt | DateTime | 更新时间 |

索引：
- `(appId, chapterId)`：按应用+章节查询评论
- `(userId)`：按用户查询评论
- `(appId)`：按应用查询评论

## 数据库迁移

### SQLite → PostgreSQL

```env
# 开发环境
DATABASE_URL="file:./dev.db"

# 生产环境
DATABASE_URL="postgresql://user:password@localhost:5432/comments_db?schema=public"
```

切换数据库后需要：

```bash
# 重新生成 Prisma 客户端
npm run db:generate

# 推送数据库结构
npm run db:push
```

注意：SQLite 和 PostgreSQL 的类型系统不完全兼容，切换前请备份数据。
