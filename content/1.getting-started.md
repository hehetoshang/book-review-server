# 快速开始

## 环境要求

- Node.js >= 18
- MySQL >= 5.7
- npm >= 9 (或 yarn / pnpm)

## 安装步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`：

```bash
cp .env.example .env
```

修改 `.env` 中的 MySQL 连接信息：

```env
DATABASE_URL="mysql://user:password@localhost:3306/brs"
JWT_SECRET="your-super-secret-key-change-in-production"
JWT_EXPIRES_IN="7d"
```

### 3. 生成 Prisma 客户端

```bash
npm run db:generate
```

### 4. 运行种子脚本

```bash
npm run db:seed
```

种子脚本会检查并创建（如不存在）：
- 管理员账号：`admin@example.com` / `admin123`
- 演示用户：`user@example.com` / `user123`
- 一个演示应用

> 注意：种子脚本兼容原有数据，已存在的账号不会重复创建。

### 5. 启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:3000` 启动。

## 访问入口

| 入口 | URL |
|---|---|
| 管理后台登录 | `http://localhost:3000/admin/login` |
| 管理后台首页 | `http://localhost:3000/admin` |
| 嵌入式评论组件 | `http://localhost:3000/embed?appId=xxx&chapterId=123` |
| 本文档 | `http://localhost:3000/docs` |
| JS SDK | `http://localhost:3000/sdk.js` |

## 数据库操作

```bash
# 打开 Prisma Studio 可视化管理数据库
npm run db:studio

# 重新生成客户端
npm run db:generate
```

## 原有数据兼容

本项目直接连接你的 MySQL 数据库，字段与原有表完全兼容：

| Prisma 模型 | MySQL 表名 | 说明 |
|---|---|---|
| User | `readers` | 原有用户表 |
| Comment | `reviews` | 原有评论表 |
| ReviewBook | `review_books` | 原书籍表 |
| ReviewChapter | `review_chapters` | 原章节表 |
| App | `apps` | 新增：应用表 |
| ThirdPartyUser | `third_party_users` | 新增：第三方用户映射 |
| Nonce | `nonces` | 新增：防重放 nonce |

**无需迁移数据**，原有用户和评论数据可直接使用。只需运行 `db:generate` 生成客户端，然后 `db:seed` 创建管理账号即可。

## 生产部署

```bash
# 构建
npm run build

# 预览
npm run preview
```

生产环境建议：

```env
DATABASE_URL="mysql://user:strong-password@prod-mysql:3306/brs"
JWT_SECRET="使用 openssl rand -base64 48 生成"
NODE_ENV="production"
```
