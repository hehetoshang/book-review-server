# 嵌入方式

评论组件支持多种嵌入方式，适用于不同的技术栈和使用场景。

## 方式一：Iframe 直接嵌入

最简单的方式，直接在页面中嵌入 iframe：

```html
<iframe
  src="https://your-comments-server.com/embed?appId=app_xxx&chapterId=123"
  style="width: 100%; border: none; min-height: 400px;"
  frameborder="0"
></iframe>
```

### URL 参数

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| appId | string | 是 | 应用 ID |
| chapterId | number | 是 | 章节 ID |
| token | string | 否 | 代理登录 token |
| theme | string | 否 | 主题：`light` 或 `dark` |
| lang | string | 否 | 语言代码，默认 `zh-CN` |
| bookId | number | 否 | 书籍 ID |
| chapterName | string | 否 | 章节名称 |
| segmentId | number | 否 | 段落 ID |
| externalId | string | 否 | 第三方用户 ID（配合 token 使用） |
| externalEmail | string | 否 | 第三方用户邮箱 |
| externalNick | string | 否 | 第三方用户昵称 |

## 方式二：JS SDK 嵌入

使用我们提供的轻量级 SDK：

```html
<!-- 引入 SDK -->
<script src="https://your-comments-server.com/sdk.js"></script>

<!-- 自动初始化（data 属性） -->
<div
  data-cc-app-id="app_xxx"
  data-cc-chapter-id="123"
  data-cc-theme="light"
></div>

<!-- 或手动初始化 -->
<div id="comments-container"></div>
<script>
  const cc = new window.ChapterComments({
    appId: 'app_xxx',
    chapterId: 123,
    token: 'optional-proxy-token',
    container: document.getElementById('comments-container'),
    theme: 'light',
    baseUrl: 'https://your-comments-server.com',
  })
</script>
```

### SDK API

| 方法 | 说明 |
|---|---|
| `setToken(token)` | 动态设置用户认证 token |
| `getCommentCount()` | 获取当前评论数 |
| `destroy()` | 销毁 iframe 并清理资源 |

### 事件监听

```javascript
const container = document.getElementById('comments-container')
container.addEventListener('cc:login', (event) => {
  console.log('User logged in:', event.detail)
})
```

## 方式三：Vue 组件

在 Vue 项目中直接使用路由：

```vue
<template>
  <iframe
    :src="embedUrl"
    class="comments-iframe"
    @load="onIframeLoad"
  />
</template>

<script setup>
const props = defineProps({
  appId: String,
  chapterId: Number,
})

const embedUrl = computed(() =>
  `/embed?appId=${props.appId}&chapterId=${props.chapterId}`
)
</script>

<style scoped>
.comments-iframe {
  width: 100%;
  border: none;
  min-height: 400px;
}
</style>
```

## 方式四：Flutter WebView

```dart
import 'package:webview_flutter/webview_flutter.dart';

class CommentsPage extends StatefulWidget {
  final String appId;
  final int chapterId;

  const CommentsPage({required this.appId, required this.chapterId});

  @override
  State<CommentsPage> createState() => _CommentsPageState();
}

class _CommentsPageState extends State<CommentsPage> {
  late WebViewController controller;

  @override
  void initState() {
    super.initState();
    controller = WebViewController()
      ..setJavaScriptMode(JavaScriptMode.unrestricted)
      ..loadRequest(
        Uri.parse(
          'https://your-comments-server.com/embed'
          '?appId=${widget.appId}'
          '&chapterId=${widget.chapterId}',
        ),
      );
  }

  @override
  Widget build(BuildContext context) {
    return WebViewWidget(controller: controller);
  }
}
```

## 方式五：React Native WebView

```tsx
import React, { useRef } from 'react'
import { StyleSheet, View } from 'react-native'
import { WebView } from 'react-native-webview'

interface CommentsProps {
  appId: string
  chapterId: number
  token?: string
}

const Comments: React.FC<CommentsProps> = ({ appId, chapterId, token }) => {
  const webViewRef = useRef<WebView>(null)

  const url = `https://your-comments-server.com/embed?appId=${appId}&chapterId=${chapterId}${
    token ? `&token=${token}` : ''
  }`

  return (
    <View style={styles.container}>
      <WebView
        ref={webViewRef}
        source={{ uri: url }}
        style={styles.webview}
        javaScriptEnabled={true}
        domStorageEnabled={true}
      />
    </View>
  )
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
  },
  webview: {
    flex: 1,
  },
})

export default Comments
```

## 高度自适应

iframe 嵌入时，评论组件会通过 postMessage 自动通知父窗口调整高度：

```javascript
window.addEventListener('message', (event) => {
  if (event.data?.source !== 'chapter-comments') return
  if (event.data?.type === 'resize') {
    iframe.style.height = event.data.data.height + 'px'
  }
})
```

SDK 已内置此功能，无需手动处理。
